# DB-001 — Corrección de CHECK inválido del modelo

Fecha: 2026-10-18. Estado: autorizado explícitamente por el usuario.

En `SistemaDeFidelizacion.json`, `roles.created_at` incluye `status IN ('owner', 'admin', 'employee')`, pero `roles` no tiene columna `status`. Se omite únicamente este CHECK en la adaptación Drizzle. Se conserva el CHECK correcto sobre `roles.rol_type` y el JSON original sin modificaciones.

Los CHECK con envoltorio `CHECK(...)` se convierten en expresiones para la API de Drizzle, sin alterar su significado. Se preservan nombres (incluido `rol_type`), longitudes, FK y acciones NO ACTION. UUID y timestamps carecen de defaults en el modelo y permanecen así.

El test de tooling compara el modelo y la adaptación aplicando solo esta excepción explícita. Si el JSON se corrige después, actualizar decisión y test en el mismo cambio. La generación SQL no prueba su aplicación real en PostgreSQL.
