# DB-002 — Corrección de relaciones de premios

Fecha: 2026-10-18. Estado: ambas correcciones autorizadas explícitamente por el usuario. El JSON original permanece intacto.

| Relación | Modelo original | Adaptación ejecutable |
| --- | --- | --- |
| fk_rewards_memberships | rewards.id → memberships.id | rewards.membership_id → memberships.id |
| fk_rewards_loyalty_ledger_entries | rewards.id → loyalty_ledger_entries.reward_id | loyalty_ledger_entries.reward_id → rewards.id |

La primera relación usaba el identificador del premio en lugar de la membresía. La segunda estaba invertida y referenciaba un campo sin unicidad; PostgreSQL rechazó el SQL original en una base temporal, dentro de una transacción revertida. La prueba de tooling de claves referenciadas reprodujo el fallo antes de corregir.

Se mantienen nombres de constraints, número de relaciones y acciones NO ACTION. El test de correspondencia normaliza exclusivamente estas dos relaciones y aplica DB-001 para el CHECK. No inferir cambios adicionales. La migración inicial local se regeneró porque aún no se había aplicado en ninguna base persistente.
